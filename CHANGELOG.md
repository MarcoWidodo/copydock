# Changelog

All notable changes are documented here. The project follows semantic versioning while it remains pre-1.0.

## [0.6.0] - 2026-10-22

### Changed

- Renamed the application, package, modules, bundle, assets, and build artifacts from SlotDock to CopyDock.
- Adopted the permanent bundle identifier `com.marcowidodo.copydock`.
- Replaced the prototype README with complete installation, usage, compatibility, privacy, development, and release documentation.

### Fixed

- Remove stale file-promise directories left by abnormal termination, including directories created by earlier SlotDock builds.

### Added

- Continuous integration, contribution guidance, security policy, issue templates, and release checklist.

## [0.5.2] - 2026-09-08

- Restored text and formatted-text preview content.
- Added thumbnails for PNG, JPEG, and other supported image-file references.
- Kept Finder file semantics and native file icons while previewing images.

## [0.5.0] - 2026-09-07

- Added configurable hover-preview bounds, palette presets, image and file previews, and expanded clipboard-format support.
- Added file-promise materialization and a configurable 5–200 MB item limit.

## [0.4.0] - 2026-09-07

- Added appearance customization, four-edge placement and snapping, proper app lifecycle, settings, hover previews, and layout recovery.

## [0.1.0] - 2026-09-07

- Introduced the nine-slot clipboard dock, numbered copy/paste, drag-and-drop, privacy filtering, and in-memory storage.
