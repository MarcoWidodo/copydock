# Third-party notices

CopyDock is an independent implementation built with Apple system frameworks and the Swift standard library. It currently has no external package dependencies and does not contain Maccy source code.

The privacy design was informed by the public behavior and documentation of [Maccy](https://github.com/p0deje/Maccy), an open-source macOS clipboard manager distributed under the MIT License. In particular, CopyDock follows the same general principle of excluding concealed, transient, auto-generated, and known password-manager pasteboard types. CopyDock's nine-slot interaction, dock UI, source code, and implementation are separate.
